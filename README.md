# 해내샵 — 결제는 지금, 배송은 해냈을 때

> PLAF 2기 This is ME Project 중간 발표작 · 임준형

## 왜 만들었나
하고 싶은 건 많은데 끝까지 해내지 못하는 제가 답답했습니다.
알람을 끄려면 사진을 찍어야 하는 앱처럼, 저에게도 **강제성**이 필요했어요.
그래서 **갖고 싶은 물건을 인질로 잡는 쇼핑몰**을 만들었습니다.

## 어떻게 동작하나
1. **목표를 편하게 적기**: "3달 동안 10kg 빼기", "토익 900점", "주 3회 크로스핏"처럼 한 줄씩 적으면
   종류·숫자·기간을 자동으로 정리 (숫자는 직접 수정 가능, 예시 버튼으로 빠르게 입력)
   - 지원: 체중, 돈 모으기, 지출, 단어, 시간 투자, 시간 줄이기, 러닝, 기상, 독서(쪽/권), 시험 점수, 주 N회, 매일 N개, 그 외 습관
2. **물건 고르고 받을 날 정하기**: 빠른 선택(내일·3일·1주·2주·1달·3달) 또는 `숫자 + 일/주/개월` 직접 입력 (최대 365일)
   - 목표에 기간이 있으면(예: 4일 동안 5kg) **목표 기간 그대로** 자동 설정 → 목표치가 바뀌지 않음
   - `가격 ÷ 기간 = 하루 ₩OOO어치의 노력` → 난이도에 따라 성공 기준(기간의 60~100%)이 정해짐 (비싼 걸 짧게 잡을수록 빡빡)
3. **도전할 목표 1개 고르기**: 내가 적은 목표를 그 기간에 맞게 환산만 함 (목표 자체는 바꾸지 않음)
   - 예) 10kg / 3달 + 2주 → "14일 동안 1.6kg 감량"
   - 무리한 페이스면 ⚠️ 경고만 표시, 낮출지는 본인이 선택
   - 결과형 목표(감량, 점수, 완독)는 마지막 날 🏁 최종 인증 추가
4. **인증 방식 고르기**: ✅ 셀프 체크 / 📸 사진 / 🏃 앱 기록(나이키 런 등) / 🤝 승인 요청
   - 승인 요청: 친구·보호자에게 링크를 보내면, 상대가 확인 후 4자리 승인 코드를 알려줌
5. **결제하면 잠김 🔒**: 기간 안에 조건을 채우면 잠금 해제 + 배송
6. **못 해내면 포인트 💜**: 결제 금액이 해내샵 포인트로 100% 전환. 포인트로 다시 사도 챌린지는 또 해내야 함
7. **인증 보너스 🎁**: 📸 사진·🏃 앱 기록으로 인증하고 (선택) 데이터 활용에 동의하면, 성공 시 1,000P 추가 적립
   - 셀프 체크·승인 요청은 보너스 없음 → 더 확실한 인증 방식을 자연스럽게 유도
   - 익명화한 인증 데이터로 "어떤 목표를, 어떤 기간에, 얼마나 성공하는지" 통계를 쌓아 성공률 예측·추천에 활용
   - 성공했을 때 한 번만 지급해서 사진만 올리는 포인트 파밍 방지

## 모드
- 🎯 **혼자**: 나와의 약속
- ⚔️ **내기**: 친구와 같은 미션으로 대결, 더 많이 해낸 사람 승리 + 진 사람 벌칙
- 🤝 **팀**: 반반 결제, 둘이 합산해서 기준을 채우면 배송
- 👨‍👩‍👧 **아이 모드**: 보호자가 아이의 목표를 정하고 승인자가 됨
